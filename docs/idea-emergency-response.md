# 아이디어: 농인 위급 상황 응대 앱 (별도 앱, 구현 전)

2026-11-12 정리. 손말하루와 다른 앱으로 만든다는 전제다. 손말하루의 대상(수어 입문 청인)은 바꾸지 않는다.

## 전제
- 실제 위급 상황의 사용자는 빠른 수어로 곤경을 표현하는 농인이고, 곁의 청인은 수어를 모른다.
- 빠른 수어는 사전 영상과 형태가 다르다(축약, 비수지 신호, 공간 지시). 사전 낱말을 익혀도 해독이 안 된다.
- 그래서 해독을 목표로 하지 않는다. 청인이 닫힌 질문을 하고 농인이 화면을 가리켜 답한다.

## 기능 후보
1. 응대 화면: 질문 버튼("어디 아파요?", "경찰 부를까요?", "병원 갈까요?") → 낱말 원본 영상 재생 → 예/아니요, 몸 그림, 통증 1~5 선택지.
2. 필담 화면: 큰 글씨 메모장과 "저는 수어를 몰라요. 여기에 써 주세요" 카드. 농인에게 한국어는 제2언어인 경우가 많아 1과 함께 둔다.
3. 공식 경로 안내: 손말이음센터 107, 112 문자신고, 119 문자·영상 신고. 앱이 이를 대신하지 않는다고 밝힌다.

## 하지 않을 것
- 카메라 수어 인식·번역(정확도와 책임 문제, AI Hub 데이터 사용 불가).

## 구현 전에 확인할 것
- 신고 번호와 운영 방식(기관 공지로 확인, 위 내용은 미검증 기억).
- 재생 속도 조절·구간 반복이 공공누리 제4유형 변경금지에 걸리는지.
- 네트워크 없이 동작하는 방법. 영상은 원본 주소 재생이라 오프라인에서 안 나오고, 저장하면 복제 금지와 충돌한다. 응대 화면은 영상 없이도 글·그림으로 돌아가야 한다.
- 질문 문구와 선택지를 농인 사용자에게 검토받기.
